# Implementation Plan: Simplify Indentation Logic

**Branch**: `010-simplify-indentation` | **Date**: 2026-03-01 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/010-simplify-indentation/spec.md`

## Summary

Remove all retroactive indentation correction (post-paste reindentation, insert-session reindentation, debounced reindent events). Keep only smart auto-indentation on new lines (Enter, `o`, `O`) controlled by the `AutoIndentation` config toggle. This is a pure deletion/simplification — no new functionality added.

## Design Decisions

### D1: Remove ReindentLines and All Callers

**What**: Delete `ReindentLines` (~100 lines), `reindentPastedRange`, `endInsertSession`, `reindentInsertSession`, `GetPrevNonEmptyLineIndent` from `indent.go`.

**Why**: These functions implement retroactive indentation correction which the user explicitly wants removed. No caller will remain after paste handlers and insert-exit handlers are updated.

**Impact**: `indent.go` goes from ~300 lines to ~110 lines.

### D2: Simplify scheduleAutoSave

**What**: Remove the `ReindentEvent` posting from `scheduleAutoSave`. The function becomes:
```go
func (e *Editor) scheduleAutoSave() {
    if e.autoSaveTimer != nil {
        e.autoSaveTimer.Stop()
    }
    e.autoSaveTimer = time.AfterFunc(autoSaveDelay, func() {
        e.saveAllModified()
    })
}
```

**Why**: `ReindentEvent` was the mechanism for debounced reindentation during insert mode. With reindentation removed, the event has no purpose.

### D3: Remove Insert Session Tracking

**What**: Delete `insertStartRow`, `insertStartCol` fields from Editor struct. Delete `startInsertSession()` function. Remove `startInsertSession()` call from `enterInsertMode()`.

**Why**: These fields tracked where insert mode began, solely for `endInsertSession`/`reindentInsertSession` to know which lines to reindent. With those functions removed, the tracking is dead code.

### D4: Clean Up ReindentEvent Type

**What**: Delete `ReindentEvent` struct and its `When()` method from `editor_insert.go`. Remove the `case *ReindentEvent` handler from `Run()` event loop in `editor.go`.

**Why**: No code will post this event after D2. Dead type.

### D5: Remove reindentPastedRange Calls from Paste Handlers

**What**: Remove `e.reindentPastedRange(buf, firstRow, lastRow)` from:
- `editor_normal.go` `p` handler (line ~217)
- `editor_normal.go` `P` handler (line ~234)
- `editor_visual.go` visual paste handler (line ~162)

Also remove the `firstRow, lastRow` return values from paste functions if they become unused (they are only used to pass to `reindentPastedRange`).

**Why**: Paste must be verbatim per FR-001.

### D6: Remove endInsertSession Calls

**What**: Remove `e.endInsertSession()` from:
- `editor_insert.go` Escape handler (line ~94, before `e.mode = ModeNormal`)
- `editor.go` F10 quit handler (line ~396)

**Why**: Insert-exit must not reindent per FR-002.
