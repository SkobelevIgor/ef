# Implementation Plan: Editor Package Test Coverage & Interface Refactoring

**Branch**: `012-editor-test-coverage` | **Date**: 2026-03-01 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/012-editor-test-coverage/spec.md`

## Summary

Refactor the `editor` package to replace concrete struct dependencies with interfaces, enabling comprehensive unit testing via `gomock`. The Editor struct currently depends directly on `*Screen`, `*FileWatcher`, `*Config`, and `*FileTypeRegistry` — all concrete types that require real terminal/filesystem resources. By extracting 5 interfaces and generating mock implementations with `mockgen`, we unblock testability and raise coverage from ~5% to 80%+.

## Technical Context

**Language/Version**: Go 1.21

**Performance Goals**: Test suite completes in <10 seconds
**Constraints**: Zero behavior regression; interfaces add negligible runtime overhead in Go
**Scale/Scope**: ~31 files in `editor/` package, ~160KB of code, targeting 80%+ line coverage
